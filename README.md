# Railway Reservation System — Portfolio & Blog

This folder contains a small static website for the C++ Railway Reservation System project.

## Files
- `index.html` — project portfolio / home page
- `blog.html` — project development blog
- `style.css` — shared responsive styling

## Publish with GitHub Pages
1. Extract this ZIP file on your computer.
2. Open your Railway Reservation System GitHub repository.
3. Select **Add file → Upload files**.
4. Upload `index.html`, `blog.html`, `style.css` and `README.md` (upload the files inside this folder, not the ZIP).
5. Select **Commit changes**.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, select **Deploy from a branch**.
8. Choose branch `main` and folder `/(root)`, then click **Save**.
9. Wait for deployment. The site URL will usually be:
   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

The portfolio home page opens from `index.html`; the blog is linked as `blog.html`.

## Project details used
The site content is based on the supplied 19-page project report. It describes a C++11 console application using `Train`, `Ticket` and `ReservationSystem` classes, STL vectors, and `trains.txt` / `tickets.txt` file storage.
